# Gabarito de Bottons Pro (Dark Studio 300 DPI)

Aplicativo web completo para criação, enquadramento, montagem de folhas A4/Carta em escala real 1:1 (300 DPI), gestão de arquivos salvos, calculadora de orçamento e controle de pedidos de bottons.

## Como publicar no GitHub e na Vercel

### 1. Pelo GitHub (GitHub Pages)
1. Crie um novo repositório público ou privado no GitHub (ex.: `gabarito-bottons-pro`).
2. Extraia este arquivo `.zip` e envie os arquivos (`index.html`, `vercel.json` e `README.md`) para a raiz do repositório.
3. No GitHub, acesse **Settings > Pages**, selecione a branch `main` e a pasta `/ (root)` e clique em **Save**.

### 2. Pela Vercel
1. Acesse [vercel.com](https://vercel.com) e clique em **Add New... > Project**.
2. Importe o repositório `gabarito-bottons-pro` do seu GitHub.
3. Não é necessário configurar comando de build (é um projeto estático puro). Basta clicar em **Deploy**.

## Dica para Impressão em Escala Real 1:1
- Ao imprimir a folha A4 ou Carta, selecione **Tamanho Real / Escala 100%** nas opções da impressora (nunca deixe em "Ajustar à página").
- Confira com uma régua física se a **Régua de Conferência** no topo da folha mede exatamente **50 mm**.
