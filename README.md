# Gabarito de Bottons Pro (Dark Studio 300 DPI)

Aplicativo web completo para criação, enquadramento, montagem de folhas A4/Carta em escala real 1:1 (300 DPI), gestão de arquivos salvos, calculadora de orçamento e controle de pedidos de bottons.

## Como publicar no GitHub e na Vercel
1. Envie o arquivo `index.html` para a raiz do seu repositório no GitHub.
2. Na Vercel, importe o repositório e clique em **Deploy**.
